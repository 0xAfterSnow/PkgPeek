Report a package

Found something malicious, or think a detection is wrong? Send it to the maintainers. Submissions go into a review queue — they do not change what the scanner flags until someone verifies the evidence and lands a change in the detection dataset.

How this works. Reports are reviewed by a human, and confirmed findings are added to the public detection dataset via pull request, so every detection is traceable to the evidence behind it. If you include a GitHub username you'll be credited in the dataset entry.
